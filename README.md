
# 🤖 AI Meeting Intelligence

AI Meeting Intelligence is an NLP-based application that analyzes meeting conversations and extracts useful information automatically.

## 🚀 Features

- 📝 Automatic meeting summary
- 👥 Participant detection
- ✅ Action item extraction
- 📅 Deadline detection
- 💡 Key decision detection
- 🧠 Meeting tone analysis
- ⚡ Meeting priority detection
- 📊 Meeting statistics
- 📥 Downloadable meeting report

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- TF-IDF
- Regular Expressions
- NLP
